# Online Transliteration

Transliteration tool for converting Russian text to Latin script. Browser-based, no dependencies, no backend.

## What It Does

Takes Russian text as input and returns the same text written in Latin characters. Intended for filling out forms, preparing documents, and generating transliterated names where Latin script is required.

## Features

- Single-page interface. Input field, one button, result.
- Responsive layout. Works on mobile and desktop.
- Copy to clipboard. One click on the result area.
- No installation, no build step. Runs directly in the browser.

## How to Use

1. Open the application.
2. Enter Russian text in the input field.
3. Click the transliterate button.
4. Copy the result.

## Stack

- HTML
- CSS
- JavaScript
- Flexbox for layout

No frameworks. No external dependencies. The entire application is client-side.

## Notes

The transliteration table follows the standard mapping used for Russian passport and document forms. It is not a phonetic transcription. If you need a different mapping — for example, for a specific country's document standard — the table is isolated in a single file and can be replaced.
